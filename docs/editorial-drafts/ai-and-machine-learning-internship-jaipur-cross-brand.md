## FAQ

### Can beginners apply?
Requirements vary. Start with fundamentals and a demonstrable portfolio project; confirm eligibility for the specific programme.

### Is a stipend guaranteed?
No. Written programme terms determine stipend, fee, certificate and any placement assistance.

### What makes a good project?
A complete, tested project with documented assumptions, data provenance, accessibility or security checks and a clear explanation of tradeoffs.
