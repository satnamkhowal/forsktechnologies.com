# Forsk Technologies — Brochures

Upload approved software development, consulting, technology service, and company profile brochures as PDF files to this folder.

- Name files in descriptive lowercase kebab-case, e.g. `software-development-services-brochure.pdf`.
- Compress PDFs for fast mobile downloads and check branding, course/service details, pricing (if applicable), validity and contact information before publication.
- Preserve existing files; use descriptive versioned filenames for materially revised brochures.
- After deployment, expected public URL: `/assets/brochures/<filename>.pdf`. Test the live URL before adding a download button.
- GitHub commits only publish to the website if the deployment process includes these assets.
